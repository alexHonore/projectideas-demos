# Project demos

Interactive, static demos of five platform ideas, in three versions each (V1 classic, V2 redesign, V3 deepened with a Test lab and optional live AI).

**Open the live site:** https://alexhonore.github.io/projectideas-demos/

| Project | What it is |
| --- | --- |
| TradeDesk | Physical grain trading desk: offers, freight, allocation, reconciliation, settlement |
| LangQuest | Speak-first language learning with a content studio |
| Tayoo | Voice-first assistant for real-estate brokers |
| Nexus CTE | M&A advisory workstation for Québec SME succession (in French) |
| TenderStrike | Public tender bid preparation for Québec SMEs (in French) |

**API monitor:** the **API** button on the hub (or `#api`) shows usage and estimated cost per app and provider, with budgets, killswitches and a test for each API. It tracks this browser only, and keys you paste stay in your browser.

All people, companies, prices, tenders and documents are fictional. Nothing is sent anywhere unless you turn on the optional live AI with your own API key, which sends the text you submit to the Anthropic API under your key.

This repository is generated from a private source repository; edit the demos there.
